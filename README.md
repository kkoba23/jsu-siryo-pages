# jsu-siryo-pages

Staticrypt で暗号化された静的 HTML の **配信専用** リポジトリ。
GitHub Pages から公開され、共有パスワードを入力すると本体が復号表示される。

公開URL: https://kkoba23.github.io/jsu-siryo-pages/

## 内容物

- `index.html` — AES-256 暗号化済み HTML（Staticrypt）
- このファイル — このリポジトリの目的

ソースコード・元データ・ビルドスクリプトは別の private リポジトリで管理している。

## データ出典・著作権

全日本海員組合関西地方支部「[戦没した船と海員の資料館](https://www.jsu.or.jp/siryo/)」

本ファイルは同資料館の公開情報をもとに **個人利用範囲** で扱っている。
再配布を意図したものではない。アクセスにはパスワードが必要。
